# Glance Roadmap

What's coming to Glance, built in small public iterations. Follow along on X with **#buildinpublic**.

- **Now** — being built right now. Each item links to a GitHub issue with the full spec and ships in its own release as soon as it's ready.
- **Next** — planned for the following releases, roughly in order.
- **Later** — bigger ideas, no promises on timing.

Have an idea or want to vote? 👍 an issue, or start a thread in [Discussions → Ideas](https://github.com/glanceapphq/glanceapp/discussions/categories/ideas).

---

## Now — "Ready to post"

- [ ] Canvas aspect ratio presets: Auto, 16:9, 1:1, 4:5, 9:16 — [#1](https://github.com/glanceapphq/glanceapp/issues/1)
- [ ] Open any image in the editor: file, drag & drop, clipboard — [#2](https://github.com/glanceapphq/glanceapp/issues/2)
- [ ] Drag the finished image out of the editor into any app — [#3](https://github.com/glanceapphq/glanceapp/issues/3)

## Next

**More ways to mark up**
- [ ] Highlighter, ellipse, line and freehand tools
- [ ] Spotlight: dim everything except the area that matters
- [ ] Blur as an alternative to pixelation

**More looks**
- [ ] Custom background colours and gradients
- [ ] Image backgrounds
- [ ] macOS-style window frame around the screenshot

**Smarter**
- [ ] Copy text from anywhere on screen (OCR, on-device)
- [ ] Automatically hide emails, API keys and card numbers (on-device)
- [ ] Pin a screenshot on top of all windows
- [ ] Style presets you can save and reuse, with an optional watermark

**For developers**
- [ ] Code snippets: paste code, get a beautiful image with syntax highlighting, themes and a window frame
- [ ] Turn code from any screenshot into a clean snippet (on-device OCR)

## Later

- [ ] Scrolling capture for long pages
- [ ] Screen recording to GIF / MP4
- [ ] Device and browser mockups
- [ ] Shortcuts / App Intents support
- [ ] Selections spanning more than one display
- [ ] Recent Captures that survive a restart

## Shipped

- **1.0** — Area, window and full-screen capture · frozen screen with loupe and snapping · gradient backgrounds, padding, corners and shadow · arrows, boxes, text, counters and pixelation · copy & save · Recent Captures · custom shortcuts · open at login

---

<sub>Glance stays native, fast and fully offline: every feature on this list runs on your Mac, with no accounts and no uploads.</sub>
